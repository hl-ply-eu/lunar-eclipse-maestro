Fenêtre Journal Plantage

Dans la fenêtre de la console vous pourrez trouver les traces d’un plantage de l’application.
En cas de plantage un journal est écrit dans la section CrashReporter. Merci de me fournir aussi les circonstances précises qui ont provoqué le plantage. L’objectif est de pouvoir reproduire le problème afin de le corriger. Si vous trouvez un tourne-autour, merci de m’en faire part.

  1. Dans FICHIERS LOG > ~/Library/Logs/CrashReporter recherchez une ligne nommée Lunar Eclipse Maestro_AAAA-MM-JJ-xxxxxx_NomMachine.crash, où AAAA-MM-JJ est la date du plantage, xxxxxx un nombre entier et NomMachine le nom de votre Mac.
  2. Faîtes moi ensuite parvenir les informations présentes dans le journal du plantage (fichier .log).
