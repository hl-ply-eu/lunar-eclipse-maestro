Fenêtre Météorologie

Les données météorologiques vous aideront à sélectionner le meilleur lieu d’observation pour l’éclipse de lune. Pour cela vous devez ouvrir la fenêtre Météorologie depuis Lunar Eclipse Maestro.
Les données météorologiques sur 25 ans de l’International Satellite Cloud Climatology Project (ISCCP) permettent de générer des cartes qui fournissent des indications précieuses comme la couverture nuageuse moyenne, le taux moyen de nuages bas, l’épaisseur moyenne de ces nuages et la température au sol moyenne.
Les données ont été prétraitées pour fournir une tendance générale et les zones de visibilité de l’éclipse sont affichées en surimpression.

Des prévisions météo locales à 3 jours sont aussi disponibles et nécessitent un accès Internet. Ce service est fourni par 7Timer.

  1. Dans le menu Affichage sélectionnez Météorologie…

    Vous pouvez choisir le type de données et le mois visualisés avant d’enregistrer éventuellement l’image dans un fichier PNG (en cliquant soit sur le bouton Enregistrer sous… ou alors en utilisant le menu contextuel).
    Le menu contextuel vous permet de sauvegarder la carte courante dans un fichier au format PNG et d’afficher les prévisions météorologiques locales depuis le lieu du clic droit.
