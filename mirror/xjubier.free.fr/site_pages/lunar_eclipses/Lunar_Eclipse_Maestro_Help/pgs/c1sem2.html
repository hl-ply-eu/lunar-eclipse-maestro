Sélectionner une éclipse de Lune

Vous pouvez utiliser Lunar Eclipse Maestro pour naviguer à travers plusieures éclipses de Lune.

Pour choisir une éclipse de Lune, procédez comme ci-dessous:

  • Dans le menu Configuration sélectionnez Choix de l’éclipse de Lune puis choisissez l’éclipse dans le sous-menu.

Pour visualiser ou modifier les éléments de Bessel des éclipses de lune, procédez comme suit:

  • Dans le menu Configuration sélectionnez Choix de l’éclipse de Lune puis choisissez Ouvrir le fichier des éléments de Bessel… dans le sous-menu.

Lunar Eclipse Maestro peut gérer jusqu’à 50 éclipses de Lune à partir du moment où les éléments de Bessel sont fournis. La modification des éléments de Bessel ne doit se faire que si vous comprenez leur signification.
