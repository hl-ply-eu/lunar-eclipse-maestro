Fenêtre Journal Application

Dans la fenêtre de la console vous pourrez trouver quelques informations de débogage ainsi qu’une trace des actions qui ont été effectuées.
En cas de plantage, merci de me fournir le résumé du plantage et les circonstances précises qui provoquent le plantage. L’objectif est de pouvoir reproduire le problème afin de le corriger. Si vous trouvez un tourne-autour, merci de m’en faire part.

  1. Dans FICHIERS LOG > ~/Library/Logs recherchez une ligne nommée LunarEclipseMaestro.log.
  2. Contrôlez les informations présentes dans le journal (fichier .log).
