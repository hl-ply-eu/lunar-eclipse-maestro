Fenêtre Propriétés Disponibles

Pour visualiser les propriétés disponibles d’un appareil numérique, vous pouvez ouvrir la fenêtre Propriétés Disponibles dans Lunar Eclipse Maestro. Cette fonctionnalité n’est disponible que lorsque au moins un APN est connecté.

  1. Dans le menu APN sélectionnez Propriétés Disponibles…
  2. Ce sont toutes les valeurs qui peuvent être utilisées dans un script pour un appareil numérique donné.
