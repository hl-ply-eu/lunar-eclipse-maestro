Remerciements

Si l’application a un comportement bizarre, alors quittez là et recommencez.

Dans la fenêtre de la console vous pourrez trouver quelques informations de débogage.
Les expositions et un certain nombre d’actions sont journalisées pour permettre une meilleure compréhension des problèmes.
En cas de plantage, merci de me fournir le journal du plantage et les circonstances précises qui le provoquent. L’objectif est de pouvoir reproduire le problème afin de le corriger. Si vous trouvez un tourne-autour, merci de m’en faire part.

Le support technique est accessible depuis http://xjubier.free.fr/support/.

  1. Pour visualiser ces informations de débogage, lancez l’application Console située dans votre dossier Utilitaires.
  2. Dans FICHIERS LOG > ~/Library/Logs recherchez une ligne nommée LunarEclipseMaestro.log.
  3. Contrôlez les informations présentes dans le journal (fichier .log).
  4. Pour un plantage, il vous faut aller voir dans CrashReporter ou vous trouverez certainement un autre fichier Lunar Eclipse Maestro_AAAA-MM-JJ-xxxxxx_NomMachine.crash où AAAA-MM-JJ est la date du plantage, xxxxxx un nombre entier et NomMachine le nom de votre Mac. Vous devez ensuite m’envoyer le contenu de ce fichier et les circonstances exactes du plantage afin que je puisse essayer de le reproduire avant de corriger le problème.
    Si un script était en cours d’exécution au moment du plantage, alors fournissez le moi aussi.

Questions Fréquentes

Q: Mon APN saute des expositions!
R: Vous essayez probablement de prendre trop de photos trop rapidement. Pour solutionner le problème vous devez:
  • Espacez les expositions un peu plus. Avec les APNs les plus lents, trois secondes ou plus entre chaque exposition peuvent être nécessaires. Avec les plus rapides, notamment ceux utilisant des cartes mémoire XQD ou CFast, une demi-seconde peut être suffisante.
  • Utilisez la carte mémoire la plus rapide fonctionnant sur votre appareil.
  • Cochez la case à cocher Incrémentale dans l’éditeur de script pour une majorité de vos expositions, afin que seules les modifications de réglages d’exposition soient transmises à l’APN.

Q: L’APN devrait effectuer une exposition de X secondes mais en exécute une de Y secondes?
R: Cela est généralement causé par un temps trop court entre deux expositions successives (se référer à la question précédente). Cela se produit fréquemment quand Incrémentale est activé et un important réglage n’a pas été traité par l’APN à cause d’un espacement trop court. Saupoudrer des expositions non incrémentales de temps en temps dans votre script est recommendé pour éviter ce type de problème pendant l’éclipse.

Q: Que dois-je faire quand la batterie de l’APN est vide?
R: Lunar Eclipse Maestro continue de fonctionner. Si vous avez une autre batterie, alors mettez là dans l’appareil et allumez le. Ensuite les prochaines actions seront automatiquement exécutées normalement.

Q: Mon APN n’est pas reconnu!
R: Il peut y avoir plusieures causes et vous pouvez essayer les choses suivantes:
  • Vérifiez que vous avez la dernière version de Lunar Eclipse Maestro, et que l’APN en question est officiellement supporté.
  • Essayer de connecter et d’éteindre puis de rallumer l’APN.
  • Vérifiez qu’aucune autre application n’essaye de contrôler l’APN.
  • Pour les appareils Nikon, vérifiez que le réglage de connexion est sur MTP/PTP, et non MSC.
  • Pour les Canon 5D, 20D ou 350D, vérifiez d’abord que le réglage de connexion est sur PC Connection, et non PTP. Ensuite vérifiez que vous utilisez bien la version Universal Binary de l’application car la version Intel ne fonctionnera pas avec ce type d’appareils Canon (limitation due à Canon).
  • Vérifiez que le câble USB cable est correctement connecté aux deux extrémités et si l’APN fonctionne avec une autre application.

Q: L’APN est reconnu, mais ne prend aucune photo!
R: Procédez aux vérifications suivantes:
  • Y a-t-il assez de place sur la carte mémoire pour écrire une ou plusieures images?
  • Y a-t-il un indicateur occupé allumé sur l’APN? L’appareil est alors soit en train d’écrire des données sur la carte mémoire ou alors en lecture des informations des photos déjà présentes sur cette même carte.
  • L’appareil et son objectif sont-ils réglés pour faire la mise au point automatique? Lorsque la mise au point ne peut être effectuée la photo n’est pas prise.
  • Sélectionnez APN > Appuyer sur le déclencheur > (nom de l’APN). Cela confirmera si le contrôle du déclenchement est possible.
  • Sélectionnez APN > Exposition unique avec réglages… > (nom de l’APN). Cela pourra confirmer si le contrôle des réglages d’exposition est possible. Si cela fonctionne, alors le problème est dans votre script.
  • En sélectionnant APN > Analyse des propriétés… > (nom de l’APN) vous pouvez m’envoyer les caractéristiques complètes de votre appareil afin que je regarde le problème.

Q: Cela fonctionnait avant, mais plus maintenant. Pourquoi?
R: Essayez cela:
  • Vérifiez que la batterie de l’APN est suffisamment chargée.
  • Contrôlez que votre Mac a assez de jus.
  • Vérifiez si l’APN est reconnu dans le dialogue Configuration matérielle accessible depuis Configuration > Configuration Matérielle….

Q: Mon GPS ne fonctionne pas!
R: Seuls les GPS Garmin utilisant le protocole PVT sur USB sont supportés.
Vérifiez en premier lieu que l’interface du GPS est bien positionnée sur GARMIN pour les anciens modèles et Garmin Spanner sur les plus récents. Ensuite vérifiez que le récepteur n’est pas en mode stockage de masse. Et enfin regardez si le récepteur GPS est identifié dans le dialogue Configuration matérielle. Si le GPS n’apparaît pas là, alors il n’y a aucune chance qu’il fonctionne.

Q: Je n’arrive pas à trouver le fichier LunarEclipseMaestro.log.
A: Vous travailler certainement avec Lion (MacOS X 10.7) ou une version plus récente, où le dossier Library est caché par défaut.
Pour afficher le contenu de ce dossier vous avez les options suivantes:
  • La plus simple: allez dans le Finder, puis appuyez sur la touche Option (alt) et sélectionnez le menu Aller. Tant que vous appuyez sur la touche Option le dossier Library apparaîtra dans la liste des possibilités. Sélectionnez la et une fenêtre s’ouvrira avec le contenu du dossier Library.
  • Utilisez Aller au dossier… et open ~/Library/ directement: vous devez taper Command+Majuscule+G depuis le Finder (ou Finder > Go > Go To Folder…) puis entrer ~/Library/Logs/ pour accéder temporairement au dossier Logs. Lorsque vous avez terminé fermez la fenêtre.
  • Depuis le Terminal: le dossier Library est visible depuis le Terminal et vous pouvez y accéder normalement. La commande OS X open, qui ouvre toutes les applications, fichier et fenêtres du Finder va être utile. Vous devez seulement taper open ~/Library/ puis la touche entrée.
Ou alors vous pouvez tout simplement aller dans le menu Fenêtre avant de sélectionner Journal de Lunar Eclipse Maestro.
